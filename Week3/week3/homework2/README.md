Homework 2 – Student Management System (Week 3)
Overview
For this assignment, I built a Student Management System in Java.
The project uses ArrayLists, custom classes, generics, and different manager classes to organize students, courses, and enrollments.
Some of the main features I implemented include:
- Managing students and courses
- Tracking enrollments and grades
- Calculating GPA
- Checking prerequisites
- Generating different reports
- Using generic data structures
- Practicing ArrayList operations
  This project helped me get more comfortable with object‑oriented programming and working with multiple classes in one system.

Class Descriptions
  Core Classes
- Student – stores student information like ID, name, major, GPA, etc.
- Course – stores course details such as course code, name, credits, instructor, and prerequisites.
- Enrollment – connects a student to a course and stores their grade.
  Manager Classes
- StudentManager – adds and finds students, lists them, filters by major, and calculates averages.
- CourseManager – stores courses, checks prerequisites, and lists available courses.
- EnrollmentManager – handles enrollments, assigns grades, and calculates GPA.

Reporting
- ReportGenerator – creates student, course, major, and honor roll reports.
  Generics & Utilities
- ArrayListUtils – extra ArrayList methods like swap, reverse, sum, average, merge, etc.
- GenericList – simple custom list using generics.
- GenericStack – stack implementation.
- GenericQueue – queue implementation.
- Pair – stores two related values.
  Demo Classes
- ArrayListOperationsDemo – shows how the ArrayListUtils methods work.
- ArrayListVsArrayDemo – compares arrays and ArrayLists.
- StudentManagementSystemMain – runs the whole system with sample data.


How to Run
- Open StudentManagementSystemMain.java
- Run the main() method
- The console will show the different reports and sample outputs
